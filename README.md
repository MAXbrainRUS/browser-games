# Игротека

Браузерные игры для iPhone, iPad и компьютера: **https://maxbrainrus.github.io/browser-games/**

Сначала открывается каталог, из него — игра. Каждая игра работает и пальцем, и мышью с клавиатурой,
запоминает партию и работает без интернета после первого открытия.

## Как приложение на iPhone и iPad

Откройте сайт в Safari → «Поделиться» → «На экран „Домой“». На экране появится значок «Игротека»:
открывается на весь экран, как обычное приложение. После обновления сайта новая версия подхватывается
при следующем запуске (если приложение висело в фоне, закройте его свайпом и откройте снова).
Внизу каталога видно, когда сайт собран в последний раз.

Отдельную игру тоже можно добавить на экран «Домой» — тем же способом, открыв её страницу.

## Как добавить или исправить игру

Дайте агенту задание, например:

> Добавь игру «Найди пару»: 16 карточек с эмодзи, открываешь по две, совпавшие остаются открытыми. Счётчик ходов и лучший результат.

> В «Оттенках фиолетового» добавь второй набор — оттенки зелёного, с переключателем наборов.

Агент работает по [AGENTS.md](AGENTS.md): кладёт всё в папку игры `games/<id>/`, проверяет её на
экранах телефона, планшета и компьютера и открывает pull request. Дальше:

1. В PR запускается проверка **Check**: собирает сайт и играет в каждую игру на компьютере,
   iPhone и iPad (Chromium и WebKit, движок Safari). Скриншоты всех игр — в артефакте `screenshots`
   на странице проверки (вкладка Checks → Check → Summary → Artifacts).
2. Вы сливаете PR в `main`.
3. Запускается **Deploy** и через минуту-две публикует сайт. Новая игра появляется в каталоге сама.

## Как устроено

```
games/<id>/        одна игра = одна папка: index.html, game.json (название и описание), icon.svg, game.spec.mjs (тесты)
site/              каталог, manifest, офлайн-режим (sw.js), общий скрипт игр (shared/game-kit.js)
scripts/           сборка (build.mjs), локальный просмотр (serve.mjs), заготовка игры (new-game.mjs)
templates/game/    заготовка новой игры
tests/             общие проверки всех игр
```

Сборка без зависимостей: `scripts/build.mjs` находит все `games/*/game.json`, проверяет игры, рисует
каталог и пишет `dist/`, который публикуется на GitHub Pages.

## Локально

Нужен Node.js 20 или новее.

```sh
npm install
npm run dev                       # каталог на http://localhost:8080/browser-games/
npm test                          # все проверки; скриншоты — в screenshots/
npm run new -- my-game "Моя игра" # заготовка новой игры в games/my-game/
```

`npm run dev` печатает ещё и адрес для телефона в той же Wi-Fi сети — так игру можно потрогать пальцем
до PR (офлайн-режим по такому адресу не включается, это нормально).

## Настройка репозитория на GitHub (один раз)

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
   Без этого Deploy упадёт на шаге публикации.
2. После первого слияния в `main` (или вручную: **Actions → Deploy → Run workflow**) сайт появится
   по адресу https://maxbrainrus.github.io/browser-games/.
3. Желательно: **Settings → Rules → Rulesets → New branch ruleset** для `main` (Target branches →
   Include default branch): включить **Require a pull request before merging** и
   **Require status checks to pass** с проверкой **test** (из workflow Check). Тогда сломанная игра
   не попадёт на сайт.
